Composition of the training data

The module retains the Allexivirus sequences its profiles were built from, because a split does not delete profiles from the parent. For most features that is harmless redundancy. For NABP it inverts the balance: the feature is trained 338:54 on Allexivirus against Potexvirus, for genomes that now route to a different module, and it is called on only 5 of 170 genomes here.

Lolavirus has four sequences per feature and no rep contig. The genus holds 10 genomes, never earned a reference at the 25-contig budget, and rides entirely on Potexvirus homology for its calls. It is named in the module and effectively unmodelled.

Profile identifiers

Profiles are named Alphaflexiviridae.<FEATURE>.<n> with n a plain integer. Second-pass clusters — built from the leftover pool that reached no first-pass cluster — continue the same integer sequence rather than carrying a prefix.

Earlier builds named them lo1, lo2 … That prefix was visible provenance but it leaked a build-pipeline detail into a permanent identifier: the id is written into every annotated genome as family_assignments → ["LOWVAN", "<Module>.<FEAT>.<id>", …], so a second id shape existed only in modules this kit built. 133 profiles in this module were renumbered.

Split children keep their underscore form (12_1, 12_2): those come from N-terminal re-clustering and the relationship is worth keeping visible.

Small profiles

63 of 259 profiles hold two sequences or fewer. That is deliberate, not neglect. The leftover pool is defined by having failed the feature's member floor, so reapplying that floor guarantees nothing returns; the floor drops to 2 for the second pass only, while clustering identity continues to do the quality work. The leftovers are the divergent members, which is the population a profile set most needs to cover.

Rebuilding

cp -R modules/Alphaflexiviridae/PSSM-Alignments  mywork/Alignments/Alphaflexiviridae
cp    modules/Alphaflexiviridae/Alphaflexiviridae_Viral_PSSM.json  mywork/
cp -R modules/Alphaflexiviridae/Rep-Contigs      mywork/
python3 skill/scripts/pssms_from_alignments.py --workdir mywork \
        --module Alphaflexiviridae --write
python3 skill/scripts/install_module.py --workdir mywork --repo <Viral_Annotation> --check

rebuild_pssms.py is not the tool for this — it refreshes profiles that already exist and reports success against an alignments-only tree without creating anything.
