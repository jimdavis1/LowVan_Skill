Does the divergent kolmiovirus module actually work?

Until 2018 hepatitis delta virus had no known relatives. Then delta-like agents turned up in snakes, rodents, bats, birds, fish, newts, toads and termites — the same circular ~1.7 kb rod-like genome, the same conserved antigen, and no editing. They make one antigen, not two. This module annotates them, and it exists as a separate module for one specific reason, measured rather than assumed.

01Why this is its own module

Not taxonomy. A feature that cannot be separated from its hepatitis delta virus counterpart by any score.

DAg and the hepatitis delta virus S-HDAg are the same protein, in different lineages, on the same locus. Inside one module the annotator called both on 601 of 660 genomes — on one genome all three features landed on the same strand within 36 nt.

No bit cutoff fixes it. DAg scores 35–442 bits on hepatitis delta virus and 157–432 on its own genomes: fully interleaved, no gap. But the winner per genome was right 660 times out of 660, and rep-contig routing reproduces that split 659 of 659 under the annotator's own blastn. So the family is partitioned by reference set, which needs no change to the shared annotator.

One genome crossed over during the audit — the white-tailed deer deltavirus ov-mh1 reached the hepatitis delta virus references by a 12-bit margin, 489 against 477. Adding it as its own reference moved it to 2,684 bits against this module. It was the only cross-module error in 652 genomes, and there is now none.

02One antigen, and how we know

The experiment decides this, not the sequence.

The snake kolmiovirus was tested directly: mutating the ORF2 initiation codon produced no translation from it and no second antigen (PMID 42842300). Chang and colleagues report no editing in the rodent, bat, bird or fish agents (PMID 31321078). So this feature is called without internal_stop and without transl_except.

That matters because several of these genomes do carry an amber codon with a downstream terminator in exactly the arrangement hepatitis delta virus uses. Reading the sequence alone, you would model two forms. The experiment says there is one. Naming them “Small delta antigen” would assert a large form that does not exist.

Thirteen of these genomes are still filed by BV-BRC under genus Deltavirus — termite agents, bat and rodent deltaviruses, the fish and avian HDV-like agents, Epsilon virus. ICTV moved them. Both the scores and the routing agree with ICTV, so the module follows the sequence and not the metadata column.

04Where the threshold sits, and why it had to be measured

A one-member collection cannot tell you what its profile scores on anything else.

The group is sparse and deeply divergent — the core genera sit at 51–64% identity to one another and 29% or less to the outliers — so the single feature carries one profile per homology group, and 13 of the 16 are built from a single deposit. A cutoff generated from a one-sequence collection is not a measurement, so these were measured against the annotator's own per-hit trace.

05What was missed

The limit here is sampling, not curation.

The profile recovers 100% of its collection (29/29) and no feature is declared without one. But ten genera are represented by one or two deposits each, and a profile built from a single sequence can only be as general as that sequence. New hosts will keep arriving faster than references for them.

The vocabulary saturation page for this module is in declined form on purpose: only 15 genomes are annotated by both BV-BRC and this module, below the floor of 40, so the raw collapse is reported rather than a rarefaction curve drawn from too little data.
