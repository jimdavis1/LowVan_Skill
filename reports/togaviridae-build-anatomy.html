Where the judgement is, and whose code does the rest

The kit's organising rule is that anything algorithmic is a script and anything requiring judgement is written instructions. That rule says what belongs in code, but not where the judgement actually falls. This is the shape of a build: twenty-one steps in four phases, each marked for whether it runs the same every time or needs someone to decide, and for whose code carries it.

The flow

Two properties are encoded separately, because they are separate questions. The shape says whether a step is deterministic. The colour says whose code runs it.

Three things the shape tells you

Judgement does not end when coding starts. It is heaviest in phases 1 and 3 — deciding what the module is, and what its features are called — but it reappears in the last phase, in deciding what the evaluation numbers mean. Budget for thinking at the end, not only at the beginning.

The kit carries the machinery, and you should let it. Clustering, profile construction, install, whole-taxon evaluation and the quality path all run unchanged. Code written during a build should be the parts the kit says are yours — the collection builder and the JSON generator — plus measurements.

Expect to measure at every step rather than trust it. The failures worth fearing in this pipeline do not raise errors; they return a plausible answer. A profile trained on truncated sequences, a check run with the wrong search parameters, a stale file left behind by an install — each produces output that looks right. Nearly every defect found in a real build was found by measuring, not by a crash.

What to expect on your taxon

Of the 22 components written during that build, roughly half were taxon-specific by design — the collection builder and the JSON generator, which the kit says to replace every time. The rest were measurements: surveys of the source vocabulary, of sequence termini, of where profiles stop matching, of routing under the annotator's own parameters. Those transfer, and a second taxon of similar shape reuses most of them.

The ratio to plan around is therefore not 22 new scripts but about a dozen, plus however much judgement the taxon's biology demands — which is the part no kit can shorten.
